# 나이스 학교생활기록부 문장 도우미

초등학교 담임교사가 나이스(NEIS)에 넣을 문장을 만들고, 검토하고, 옮기는 것을 돕습니다.

**문장을 만드는 데 AI를 쓰지 않습니다.** 토큰이 들지 않고, 계정도 필요 없고,
인터넷이 끊긴 교실에서도 동작합니다. 문장은 안에 들어 있는 **2,376개 문장 자산**을
규칙으로 조립해 만듭니다.

---

## 바로 쓰기

<!-- 아래 주소는 저장소를 올린 뒤 본인 것으로 고치세요 -->
**https://<내-계정>.github.io/<저장소-이름>/**

주소만 알려 주면 다른 선생님도 바로 쓸 수 있습니다. 설치할 것이 없습니다.

처음 열면 **예시 학급 둘러보기**가 있습니다. 가상의 4학년 24명이 들어 있으니
먼저 눌러 보세요. 실제 학생이 아니고, 아무 데도 저장되지 않습니다.

## 무엇을 만들어 주나

학기마다 아래를 번호순으로 만듭니다.

| 묶음 | 항목 | 글자 상한 |
|---|---|---|
| 행동특성 및 종합의견 | 1개 | 400자 |
| 학기말 종합의견 | 과목 수만큼 | 380자 |
| 창의적 체험활동 | 자율 · 동아리 · 진로 · 봉사 | 250자 |

### 나이스로 옮기는 세 가지 길

1. **순서대로 붙여넣기** — 한 번호씩 복사해 줍니다. 붙여넣는 것은 선생님이 합니다.
   **이 프로그램은 나이스 화면을 건드리지 않습니다.** 탭 횟수는 끝까지 같습니다
   (학기말 3번 · 행동특성 2번 · 창체 누가기록 2번).
2. **나이스 엑셀 채우기** — 나이스에서 받은 파일을 올리면 번호를 맞춰 문장 열만 채워 돌려줍니다.
3. **창체 엑셀 내려받기** — 나이스 내려받기 파일과 같은 모양으로 새로 만듭니다.
   시트 이름·머리글 8칸·열 너비·줄바꿈 서식까지 같고, 학생개인번호와 성명은 비웁니다.

## 문장은 어떻게 만들어지나

```
갈래를 고른다           →   그 갈래의 문장 변형 10개 중 하나를 뽑는다
(예: 책임과 역할 · 궂은일 자원)      ↓
관찰 장면을 적는다       →   뽑은 문장 뒤에 그대로 붙인다
         ↓
번호마다 다른 변형이 가도록 돌리고, 겹치면 다시 뽑는다
```

- **갈래**: 행동특성 12 · 학기말 6 · 창의적 체험활동 4영역 + 꼬리(참여 태도·역할·기여·전이)
- **항목**: 236개. 항목마다 문장 변형이 10~12개씩 들어 있습니다.
- **겹침 방지**: 생성한 뒤 번호끼리 재어 보고, 겹친 번호만 다시 뽑습니다.
  한 반 30명 전원이 같은 창체 활동을 해도 문장이 모두 달라집니다.

### 지키는 규칙

- 어미는 `~함` `~임` `~보임` — **과거형을 쓰지 않습니다.**
- 추상 평가어(착함·성실함·훌륭함…), 성격 단정, 약점을 결과로 적은 말을 쓰지 않습니다.
- 대회명·학교명·지역명·사람 이름 같은 고유 정보를 쓰지 않습니다.
- 약점은 **변화 과정**으로 씁니다.
- 선생님이 쓰신 **관찰 장면**이 위 규칙에 걸리면 화면에서 짚어 주고, 그 장면은 문장에 넣지 않습니다.

자세한 내용은 [`docs/기록부-작성-규칙.md`](docs/기록부-작성-규칙.md)에 있습니다.

## 내 것으로 올리기 (GitHub Pages)

1. 이 저장소에서 오른쪽 위 **Fork** 를 누릅니다.
2. 포크한 저장소에서 **Settings → Pages** 로 갑니다.
3. **Source** 를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)` 로 두고 **Save**.
4. 1~2분 뒤 `https://<내-계정>.github.io/<저장소-이름>/` 가 열립니다.

> 저장소를 **Public** 으로 두어야 무료 계정에서 Pages가 열립니다.

## 입력한 내용은 어디에 저장되나

- **이 브라우저 안에만 저장됩니다.** 서버로 보내지 않습니다.
- **학생 이름은 프로그램 어디에도 저장하지 않습니다.** 번호만 씁니다.
- 기기를 옮기거나 백업하려면 **표로 내려받기**로 파일을 받아 두세요.
- 브라우저 데이터를 지우면 함께 사라집니다. **중요한 고비마다 한 벌씩 받아 두세요.**
  (전체 생성을 다시 돌리기 전 · 맞춤법 점검을 돌리기 전 · 학급을 지우기 전)

## 문장을 우리 학교 말투로 고치기

화면 위 **문장 자산** 을 누르면 2,376개 문장을 직접 고칠 수 있습니다.
고친 것은 **내보내기** 로 파일로 저장해 다른 선생님과 주고받을 수 있습니다.

> 학교마다 자기 표현으로 다듬어 쓰면 다른 학교와 겹칠 걱정이 사라집니다.

코드로 고치려면 `src/corpus/*.js` 를 고친 뒤 `sh tools/build.sh` 를 돌리세요.

## 저장소 구성

```
index.html              앱 본체 (GitHub Pages 진입점)
vendor/                 한글·엑셀 파일을 만들 때만 쓰는 라이브러리
                        JSZip 3.10.1 (MIT) · SheetJS 0.18.5 (Apache-2.0)
src/
  base-app.html         화면과 기능의 원본 (문장 엔진 이전 상태)
  corpus/*.js           문장 자산 2,376개 — 여기를 고칩니다
  parts/*.js            규칙 엔진 · 점검 · 화면 조각
tools/
  build.sh              index.html 을 다시 만듭니다
  gen-data.mjs          corpus → 코드
  patch.py              base-app + parts → index.html
  sensors/              자동 점검 7종
docs/                   규칙·명세·비기능 요구
```

### 고치고 다시 만들기

```bash
node --version          # 18 이상
python3 --version       # 3.8 이상
sh tools/build.sh       # 문장 자산 → index.html, 점검까지 한 번에
```

### 점검만 돌리기

```bash
sh tools/sensors/run-all.sh
```

| 번호 | 무엇을 보는가 |
|---|---|
| 01 | 학급 데이터가 내 계정 밖으로 새지 않는지 |
| 02 | 나이스 화면을 건드리는 코드가 있는지 |
| 03 | 문장을 만들 때 AI를 부르는지 |
| 04 | 문장 자산의 길이 · 어미 · 금지어 · 중복 |
| 05 | 24명 결과의 다양성과 글자 수 (Playwright 필요) |
| 06 | 확인 못 한 것을 확인한 척하는 문구가 있는지 |
| 07 | 과거형이 섞여 있는지 |

05번만 Playwright가 필요합니다. 없으면 건너뛰되, **건너뛴 것을 통과로 세지 않습니다.**

```bash
pip install playwright && playwright install chromium
```

## 이 프로그램이 하지 못하는 것

정직하게 적어 둡니다.

- **사람 이름을 걸러내지 못합니다.** 성씨로 찾으면 `나누어`·`함께`·`하는` 까지 잡혀
  오탐이 너무 많아 포기했습니다. 관찰 장면에 이름을 쓰지 않도록 선생님이 확인해 주세요.
- **맞춤법은 규칙 32가지만 봅니다.** 목록에 없는 것은 그냥 지나갑니다.
  그래서 화면 어디에도 "맞춤법 검사 완료"라고 쓰지 않습니다.
- **어미를 자동으로 바꾸지 않습니다.** ㅂ/ㄷ/ㅅ/르 불규칙에서 기계 변환이
  조용히 틀립니다(`돕는다 → 도우움`). 틀렸다고 짚어 주기만 합니다.
- **문장 품질은 안에 든 2,376개가 전부입니다.** 관찰에 없는 내용을 지어내지 않습니다.
- **만들어 준 문장을 그대로 올리지 마세요.** 초안입니다. 눈으로 읽고,
  실제로 있었던 일인지 확인한 뒤 올려 주세요.
